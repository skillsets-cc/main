## CLI security surfaces

- Command injection: execSync only on hardcoded strings; all dynamic data uses spawnSync with array args
- Path traversal: Skillset IDs validated with strict regex (/^@[A-Za-z0-9_-]+\/[A-Za-z0-9_-]+$/); file ops bounded to CWD
- YAML deserialization: js-yaml v4+ safe by default (no unsafe type constructors)
- Checksum verification: Temp-dir clone → verify → copy pattern prevents TOCTOU
- API URLs: All hardcoded to <https://skillsets.cc/>..., no user-controlled host/protocol
- Input validation: Strict regexes on name, author, version, handle, tags before use in paths or git commands

  One near-miss (confidence 7/10, below reporting threshold): checksum.ts:47-52 could theoretically allow path traversal via malicious search-index.json keys, but exploitation requires
  CDN/build pipeline compromise. Fix would be adding path.resolve() bounds check — low priority.
